# 실기기 검증 체크리스트 (MANUAL_VALIDATION)

자동 테스트는 합성음·공개 데이터셋(GuitarSet)·가짜 마이크로 판정기를 검증했습니다. **내 기타, 내 방, 내 기기의 마이크**에서도 맞는지는 아래 순서로 직접 확인해야 합니다. 한 기기당 30–40분.

## 0. 준비

- 기기: MacBook(Chrome, Safari), iPad(Safari → 홈 화면에 추가한 앱), iPhone(Safari). 배포 주소 또는 `npm run dev:https`([DEPLOY.md](DEPLOY.md) 6절).
- 기타는 새 줄이 아니어도 되지만 크게 녹슬지 않은 것. 조용한 방. 기기를 기타에서 30–60 cm, 사운드홀을 향하게.
- 비교용 튜너(클립 튜너 또는 신뢰하는 튜너 앱).

## 1. 처음 설정(캘리브레이션)

- [ ] 마이크 허용 → 진단(설정 > 입력 장치·진단)에서 에코 제거·잡음 제거·자동 음량이 **꺼짐**으로 보이는가? (Safari는 "알 수 없음"일 수 있음 — 기록)
- [ ] 소음 측정 값(dBFS)을 기록. −45 dBFS보다 크면 경고가 뜨는가?
- [ ] 6줄 튜닝 통과. 지연(RTT) 측정이 **스피커 루프백**으로 성공했는가? 두 번 측정 값이 3 ms 안인가? 실패하면 탭 보정으로 넘어가는가?
- [ ] 블루투스 이어폰을 연결한 상태에서는 "블루투스" 경고와 탭 보정 안내가 나오는가?

## 2. 튜너를 다른 튜너와 비교

- [ ] 튜너 화면(줄 모드)과 비교용 튜너로 같은 줄을 동시에 잽니다. 6줄 × 2회.
- [ ] 두 값의 차이가 대부분 ±3 cents 안인가? "맞음"이 비교 튜너도 맞다고 할 때 뜨는가?
- [ ] 크로매틱 모드에서 저음 E2(6번 줄)를 한 옥타브 위(E3)로 잘못 읽지 않는가?

## 3. 코드 정밀 체크(E1) — 일부러 뮤트

코드 라이브러리 → C → "이 코드로 정밀 체크".
- [ ] 깨끗하게 잡고 한 줄씩: 5줄 모두 "깨끗"(6번 줄은 "치지 않는 줄")인가?
- [ ] 2번 줄을 손가락 바닥으로 살짝 막고 다시: 2번 줄이 "막힘" + 코칭 문구가 나오는가?
- [ ] 3번 줄 대신 2프렛을 누르는 식으로 **다른 음**을 내면 "다른 음"이 나오는가?
- [ ] 스트럼(베타) 모드에서 6번 줄까지 쳤을 때 "6번 줄이 울렸어요"가 나오는가? (확인 불가 줄은 정상)
- [ ] 같은 실험을 Em, D, G로 반복(가능하면).

## 4. 1분 체인지(E2) — 자동 카운트 vs 직접 센 값

- [ ] A ↔ D 1분을 하며 바꾼 횟수를 속으로 셉니다. 끝난 뒤 자동 값과 비교(±1 안이면 좋음). 3회.
- [ ] 소리를 일부러 지저분하게 쳐도 카운트가 크게 틀어지지 않는가?
- [ ] ↑/↓로 보정한 값이 저장되는가(진도 화면)?

## 5. 스트럼 타이밍(E5)

- [ ] P0 60 BPM 8마디를 메트로놈(소리)에 맞춰 칩니다 → 적중률·평균·흔들림 기록.
- [ ] **시각 전용 메트로놈**(설정)으로 같은 실험 → 클릭 소리 없이도 판정이 되는가?
- [ ] 일부러 반 박씩 늦게 쳤을 때 평균이 + 쪽으로 크게 나오는가?

## 5b. 실사용 보강 (커리큘럼 직접 연습·즉시 피드백·판정 감도, D-072–D-077)

- [ ] **몸통 노크(E1 한 줄씩)**: C를 잡고 5번 줄 차례에 기타 앞판·옆판을 손가락이나 피크로 톡 친다 → "막힘"이 아니라 "줄 소리가 아닌 것 같아요… 한 번 더"가 뜨고 같은 줄을 계속 기다리는가? 이어서 그 줄을 치면 정상 판정되는가? (판정 감도 둔감·보통·민감 각각)
- [ ] **일부러 뮤트한 줄**: 2번 줄을 손가락 바닥으로 막고 쳤을 때 여전히 "막힘"이 나오는가(바로, 또는 "한 번 더" 뒤 두 번째에)?
- [ ] **앞 줄이 울리는 채로**: 앞 줄을 세게 치고 손을 떼지 않은 채 다음 줄을 약하게 친다 → 다음 줄이 "깨끗"으로 나오는가? 다음 줄을 일부러 한 프렛 틀리게 → "다른 음"인가?
- [ ] **빠른 줄 넘김**: 다음 줄이 표시되기 전에(앞 줄을 치고 0.5초쯤 뒤) 다음 줄을 친다 → 그 소리가 다음 줄 판정에 쓰이는가(다시 치라는 말 없이)?
- [ ] **즉시 피드백 E6**: 박 1 체인지 60 BPM에서 3마디째 첫 박을 일부러 늦게, 5마디는 쉬기 → 마디가 끝나고 1초 안에 3마디 "±(늦게 … ms)", 5마디 "■ 멈춤"이 뜨는가? 바꾸는 마디에서 일부러 앞 코드를 다시 치면 "앞 코드 소리 같아요"가 뜨는가? 끝난 뒤 요약의 "제때 마디 수"와 칸의 ✓ 수가 같은가?
- [ ] **즉시 피드백 E5·E8**: 패턴 칸 아래 맞음(✓)·놓침(✗)·더 친 것(+)이 마디마다 바뀌는가?
- [ ] **커리큘럼 직접 연습**: 지금 단계가 아닌 단계 페이지에서 "바로 하기" → 그 단계 코드·템포로 실행되는가? 두 개를 골라 "세션 시작" → 고른 순서로 진행되고, 지금 단계의 최소 세션 수는 그대로인가?
- [ ] 가능하면 설정 > 녹음 키트로 노크·뮤트·빠른 줄 넘김 장면을 녹음해 두기(다음 조정 근거).

## 5c. 하는 법·리프 안내·홈 오늘 한 연습 (D-078–D-080)

- [ ] **리프 TAB**: iPhone 세로 화면에서 줄 번호·마디선·손가락 행이 읽히는가(글자가 너무 작지 않은가)? "말로 읽은 리프"와 TAB이 같은 음인가?
- [ ] **들어 보기**: 리프 준비 화면에서 "들어 보기(M)" → 소리가 나오고, 듣는 중 Space로 시작하면 소리가 바로 멈추고 첫 바퀴 판정이 정상인가(마이크가 데모를 듣지 않음)?
- [ ] **복습 표시(D-081)**: 코드 기억 퀴즈를 한 다음 날 홈 "오늘 복습 n개"가 0이 아니고 코드 기억 퀴즈에 "복습" 배지가 붙는가? 진도 화면 "지금 복습할 것" 목록과 같은 코드인가?
- [ ] **연습곡 숨김 단계(D-082)**: 연주 단계를 한 번 끝까지 친 다음 세션에서 그 곡 준비 화면에 "이번부터 숨김 단계예요"와 악보가 보이고, 시작(첫 스트럼 또는 Space)하면 악보가 가려지고 마디 번호만 보이는가? 같은 세션에서 한 번 더 하면 안내가 다시 뜨지 않는가?
- [ ] **한글 입력 키(D-083)**: 한글 입력을 켠 채로 연습곡에서 H·M·B가 동작하는가?
- [ ] **일시정지(D-085)**: 연습곡·E5·E6·E8·스케일·리프에서 마디 중간에 P → 메트로놈·반주가 멈추고, P(또는 Space) → 한 마디 세고 끊긴 마디부터 이어지는가? 마이크 판정이 이어 한 뒤에도 정상인가(이어 한 첫 마디가 '멈춤'으로 나오지 않음)? 세션에서 일시정지한 동안 블록 시간이 줄지 않는가? 요약에 "진급 기준에는 쓰지 않아요"가 보이는가(연습곡은 멈춤 1로 셈)?
- [ ] **처음부터(D-086)**: 연습곡 연주 중 R → 카운트인부터 다시, 끝난 기록에 앞 시도의 멈춤이 남지 않는가?
- [ ] **진급 체크리스트(D-084)**: 남은 쌍에 "30회 넘은 날 n/2일 · 최고 m회"가 보이고 실제 기록과 맞는가?
- [ ] **홈 오늘 한 연습**: 세션을 마친 뒤 홈의 "오늘 한 연습"이 실제로 한 항목·순서와 같은가? 그 아래 "한 번 더 하면" 목록에서 리듬·기술 칸이 바뀐 것이 안내 문구로 이해되는가?

## 5d. UI 마감 (D-089–D-094): safe area · 터치 · 60–80 cm 가독성 · 세 테마

자동 검사(UQ-1–UQ-10, E2E-10·11)가 재는 것은 크기·위치·대비·표식이다. 아래는 실제 기기에서만 확인할 수 있는 것이다.

- [ ] **safe area**: iPhone(노치·홈 막대)과 iPad 홈 화면 앱에서 위쪽 제목·아래 탭바·연습 화면 아래에 붙는 행동 막대가 노치·홈 막대에 가리지 않는가? iPhone을 가로로 돌려도 양옆 글자가 잘리지 않는가?
- [ ] **아래에 붙는 막대**: iPhone·iPad 세로의 연습 화면(E1·E9·연습곡)과 루틴 편집에서 주 버튼 막대가 화면 아래에 붙어 있고, 끝까지 스크롤하면 내용 뒤 제자리로 돌아가는가? 막대가 탭바 위에 있고(루틴 편집) 겹치지 않는가?
- [ ] **터치**: 기타를 안은 채 오른손으로 iPad 가로의 "시작"·"1 실수 없음"·"이어서(P)"를 누를 때 이웃 버튼을 잘못 누르지 않는가(간격 8 px 이상)? 시퀀스 연습(크로매틱·스케일·해머온·리프) 준비 화면에서 Space 없이 "시작"으로 시작되는가?
- [ ] **60–80 cm 가독성**: 보면대 거리에서 남은 시간·BPM·카운트다운 숫자, 연습 지시문(18 px 이상), TAB 숫자(iPad 가로)가 읽히는가? iPhone 세로의 긴 TAB(E10 스케일 사다리 22음)은 숫자 약 14 px로 옆으로 밀리며 현재 음을 따라가는가(D-094)? 손가락으로 옆으로 밀어 볼 수 있는가?
- [ ] **세 테마**: 다크·라이트·고대비에서 홈·연습(E1·E5·연습곡)·튜너·설정을 열어, 주 버튼(앰버/노랑)이 화면마다 하나로 보이는가? 고대비에서 코드 차트·패턴 칸·문제 카드의 칸 경계가 보이는가? 포커스 링(키보드 Tab)이 세 테마 모두에서 보이는가?
- [ ] **일시정지 포커스**: MacBook에서 연습곡 중 Tab으로 "일시정지(P)"에 포커스 → Space로 멈춤·이어 하기를 번갈아 해도 포커스가 버튼에 남는가?
- [ ] **한국어 줄바꿈**: iPhone에서 긴 안내(하는 법, 진급 기준)가 낱말 가운데서 끊기지 않는가("튜닝부/터" 같은 줄바꿈이 없는가)? 항목 제목("스트러밍 패턴 사다리 · D D D D · 60 BPM")이 패턴 글자 가운데서 갈리지 않고 "·"가 줄 끝에 남는가?
- [ ] **나가기**: 연습이 도는 중 위쪽 "나가기"를 터치하면 "그만할까요?"가 뜨고, "계속하기"로 돌아가며, "중단하기" 뒤 다시 "나가기"로 나가지는가(D-094)?

## 5e. 뒤로 가기 (D-096, D-097)

- [ ] **페달 ← 연습 중**: 세션 둘째 항목 이후에서 연습을 시작하고 첫 스트럼 전에 왼쪽 페달(←·PageUp) → 묻지 않고 앞 항목으로 가는가? 치는 중에 왼쪽 페달 → "이 연습을 끝내고 이전 항목으로 갈까요?"가 뜨고, 왼쪽·오른쪽 페달 어느 쪽이든 확인, Esc는 계속인가? 확인 뒤 앞 항목에 그 항목의 마지막 결과가 보이고 "다음 항목"에 포커스가 있는가?
- [ ] **마이크 연습 중 뒤로**: E1·E5·연습곡을 마이크로 치는 중 "이전 항목" → 확인 → 메트로놈·반주가 멈추고 마이크 판정이 앞 항목에서 정상으로 다시 시작되는가?
- [ ] **자가 평가에서 돌아가기**: 마지막 항목 뒤 자가 평가에서 ← 또는 "연습으로 돌아가기" → 마지막 항목의 결과가 보이는가? 통증 슬라이더를 만지는 중 ←가 슬라이더만 움직이는가?
- [ ] **블록 끝**: 블록 시간을 넘긴 항목에서 다음으로 갔다가 돌아오면 "블록 끝"이 바로 뜨지 않고, 그 항목 시간이 다시 지나면 끝 신호가 다시 울리는가?
- [ ] **연습 안의 ←**: 튜닝에서 ← → 앞 줄을 다시 맞춰야 하는가(마이크 판정)? E1 한 줄씩 모드에서 Next로 건너뛴 줄을 ←로 다시 판정하는가? 퀴즈에서 ← → 앞 문제가 내 답 그대로 보이고, 1/2/3·Q3 튕긴 음이 답이 되지 않는가?
- [ ] **처음 설정·시험**: 튜닝 "건너뛰기"를 잘못 누른 뒤 "이전 단계"로 튜닝이 처음부터 다시 열리는가? 지연 측정 중에는 "이전 단계"가 비활성인가? 시험 항목 3(5쌍)에서 쌍마다 결과가 보이고 다음 쌍 시작 화면에서 "← 앞 단계 결과 보기"가 앞 결과를 보여 주는가?
