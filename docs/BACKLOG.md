# v2 백로그 (BACKLOG)

v1.1 범위 밖으로 둔 항목(SPEC v1.1 §3.2)과 v1·v1.1을 만들며 보인 다음 단계. v1 백로그에 있던 E3·E9–E12, 6·5번 줄 음이름, 인터벌 귀 훈련, Stage 8–11 진행, 반주(앱 합성)는 v1.1에서 구현했다. v1.1에서 미룬(DEFERRED) 항목은 없다(SPEC §16.1 목록 전부 구현).

## v1.1에서도 제외 (SPEC v1.1 §3.2)
- 클라우드 동기화·계정·텔레메트리(서버 필요, local-first 원칙). 텔레메트리를 넣는다면 opt-in.
- 실제 곡(저작권 곡) 콘텐츠, 외부 백킹 트랙 오디오 파일(반주는 앱 합성으로만)
- calibration template 기반 NNLS 분해(스트럼 Mode B의 "확인 불가" 줄 줄이기), basic-pitch(ONNX) second opinion, WASM DSP 커널(프로파일상 필요가 증명될 때만 — 현재 판정 지연 수 ms)
- 같은 음을 다른 줄에서 내는 경우의 줄 식별(지판 음이름 퀴즈의 연주 응답은 음높이만 판정)
- 리서치 원 모듈 중 스테이지 표에 없는 것: 블루스 솔로·즉흥, 핑거스타일, 디스토션, 리프 작곡, Beginner 2 이후 과정
- 베타 판정의 게이트화(정답 데이터가 생기면 v2에서 결정)

## 판정(DSP) — 베타에서 이어지는 과제
- 스트럼 방향(베타, dev 0.54): 줄별 고유 partial 시각 대신 줄별 전사(예: Murgul et al.)로 줄 onset을 직접 추정 — 옥타브 관계가 많은 코드에서 이웃 줄 누설을 피한다(DSP.md 17절)
- 버징(베타, dev 검출 0.62): 감쇠 초반 진폭 변조·spectral flatness 특징 추가, 실녹음 버징 데이터로 템플릿 보정
- 스피커 반주 아래 Mode C(베타, dev 0.76): 반주 템플릿을 스펙트럼 차감에 써서 분류 전 반주 성분 제거 — 그러면 스피커 반주의 코드 확인을 "참고"에서 올릴 수 있다
- E10 "반주와 함께"의 스피커 판정: 단음 경로에도 반주 마스킹(이벤트 도착 시각 ± 창의 onset·음높이 제외)을 넣으면 스피커 실행을 참고에서 기록으로 올릴 수 있다(D-067)
- 실기기 녹음 키트 fixture가 쌓이면 Mode B 임계값·Mode A 뮤트 기준·시퀀스 clarity 기준 재조정(`bench:real` 결과 기준)
