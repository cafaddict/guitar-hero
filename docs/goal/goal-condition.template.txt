이 레포(guitar-hero)에 docs/goal/SPEC.md 명세대로 "완전 초보 어쿠스틱 기타 학습자용 체계적 연습 웹앱 v1"을 구현한다. SPEC.md가 승인된 계획이자 단일 진실 원천이며, 임계값과 지표 정의는 docs/goal/thresholds.json과 SPEC §14에 고정되어 있다.

작업 방식:
- 매 턴 시작 시 docs/goal/PROGRESS.md를 읽고 다음 미완료 마일스톤(M0→M8, SPEC §16)을 진행하며, 턴을 끝내기 전에 PROGRESS.md를 갱신한다.
- Plan Mode 진입·사용자 질문(AskUserQuestion) 금지. 모호하면 SPEC 기본값을 따르고, 없으면 보수적으로 선택해 docs/goal/DECISIONS.md에 기록한다.
- 브랜치 feat/practice-app-v1에서만 작업하고, 마일스톤 종료 시 npm run verify 통과 후 그 브랜치에 커밋한다. push·원격 추가·main 수정/병합·배포·force·히스토리 재작성 금지.
- SPEC.md와 thresholds.json은 수정 금지. 임계값·매트릭스·시드·E2E 단언을 완화하거나 테스트를 skip하지 않는다. DSP 파라미터는 dev split으로만 튜닝한다. GPL/AGPL 의존성 금지. 레포 밖 수정 금지(SPEC §2.3 예외 제외).
- 10분 넘는 명령(전체 verify, GuitarSet 다운로드)은 백그라운드로 실행하고 완료를 확인한다. 턴을 끝낼 때 dev server 등 백그라운드 프로세스를 남기지 않는다.

완료 조건 — 아래를 모두 충족하고, 마지막 턴에 각 증거를 명령 출력 그대로 **마지막 assistant 메시지 본문에 붙여 넣는다**(SPEC §16.2, §18.2):
1. git: `git rev-parse --short main` = 9e7eda6, `git log --oneline main..HEAD`에 M0~M8 커밋, `git status --short` 비어 있음, feat/practice-app-v1에 upstream 없음.
2. 무결성: `shasum -a 256 docs/goal/SPEC.md docs/goal/thresholds.json` 결과가 정확히
   {{SPEC_SHA}}  docs/goal/SPEC.md
   {{THRESH_SHA}}  docs/goal/thresholds.json
3. HEAD에서 실행한 `npm ci && npm run verify`가 exit 0이고 SPEC §14.7 요약표의 모든 단계가 PASS다. bench:guitarset만 SPEC §14.4의 다운로드 실패 마커가 있을 때 BLOCKED를 허용하며, 그 경우 마커 내용도 출력한다.
4. bench:dsp(합성 test split)의 모든 지표가 thresholds.json 임계값을 만족함을 보여 주는 지표표(지표·값·임계값·판정 열).
5. bench:guitarset의 하드 지표 4개 통과와 소프트 지표 값을 보여 주는 지표표.
6. docs/goal/PROGRESS.md의 AC 표 전체: 모든 AC가 DONE이고 각 행에 증거가 있다. 예외는 SPEC §16.1 목록의 하위 항목을 미룬 `DONE (deferred: …)`와, 조건 3의 경우에 한한 AC-G1~G3의 BLOCKED뿐이다.
7. docs/goal/FINAL_REPORT.md의 요약·알려진 한계·사용자 다음 할 일 절.

또는 300턴이 지나면 멈추고, 그 시점의 PROGRESS.md AC 표와 남은 작업 목록을 출력한다.
