# v2 백로그 (BACKLOG)

v1 범위 밖으로 둔 항목(SPEC §3.2)과 v1을 만들며 보인 다음 단계. v1에서 미룬(DEFERRED) 항목은 없다(SPEC §16.1 목록 전부 구현).

## 연습·콘텐츠
- 정확 빠른 체인지(E3), 크로매틱(E9), 스케일 사다리(E10), 해머온(E11), 새끼손가락 운동(E12)
- 지판 음이름 확장(6·5번 줄), 인터벌 귀 훈련
- Stage 8–11 실제 진행(콘텐츠 데이터는 v1에 있고 잠금 상태)
- 실제 곡(저작권 곡) 콘텐츠, 백킹 트랙 오디오

## 판정(DSP)
- 버징(fret buzz) 판정, 스트럼 방향(업/다운) 판정, 같은 음이 겹치는 줄 식별
- 캘리브레이션 템플릿 기반 NNLS 분해로 스트럼(Mode B)의 "확인 불가" 줄 줄이기
- basic-pitch(ONNX) second opinion
- 실기기 녹음 키트 fixture가 쌓이면 Mode B 임계값·Mode A 뮤트 기준 재조정(`bench:real` 결과 기준)
- WASM DSP 커널은 프로파일상 필요가 증명될 때만(현재 판정 지연 수 ms)

## 데이터·플랫폼
- 클라우드 동기화·계정(현재 local-first + 수동 백업)
- 텔레메트리는 넣지 않는다는 원칙 유지(넣는다면 opt-in)
- 녹음 키트 오디오를 백업 JSON과 함께 묶는 통합 백업
- Playwright WebKit에서 오프라인 서비스 워커 E2E(현재 하네스 한계로 Chromium만, D-048)
