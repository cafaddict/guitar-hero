# guitar-hero — 기타 연습 (v1.1: 초급 1 + 초급 2)

완전 초보 성인이 어쿠스틱 기타를 체계적으로 배우도록 **매일의 연습 루틴을 짜 주고, 마이크로 듣고 정직하게
피드백하며, 진도를 숫자로 보여 주는** local-first 웹앱(PWA)입니다. MacBook, iPad, iPhone 브라우저에서 동작하고
기록은 모두 내 기기 안에만 남습니다. 명세: v1.1 [`docs/goal/v1.1/SPEC.md`](docs/goal/v1.1/SPEC.md)(v1
[`docs/goal/SPEC.md`](docs/goal/SPEC.md)를 이어받음). 최종 보고: [`docs/goal/v1.1/FINAL_REPORT.md`](docs/goal/v1.1/FINAL_REPORT.md).

## 무엇을 할 수 있나

- **처음 설정**: 마이크 권한·장치, 주변 소음(마이크 환경 안내), 6줄 튜닝(±15 cents, "조이세요/푸세요"와 줄감개 방향 그림, 다른 튜너로 맞췄으면 건너뛰기), 줄별 소리 템플릿, 지연(RTT: 스피커 루프백, 안 되면 클릭에 맞춰 치기)
- **오늘의 루틴 → 세션 러너**: 단계별 시간 템플릿(20분, 단계 8부터 30분)을 채웁니다 — 튜닝, (단계 7부터) 레퍼토리, 코드, 1분 체인지 두 칸(새 코드 쌍 / 진급에 필요한데 오래 안 한 쌍), 리듬·기술 순환(목록의 각 항목이 3세션마다 한 번 이상), 코드 기억 퀴즈, 연습곡(항상 마지막). 복습은 같은 종류 블록 안에서, 템포는 사다리의 현재 BPM에서 이어 갑니다. 단계 8부터는 앞 절반(리듬 블록까지) 뒤에 "여기서 나눠 하기"가 있어 같은 날 홈의 "이어서 하기"로 나머지를 하고 한 세션으로 기록합니다. 레퍼토리 블록의 "이어서 한 번 더"는 다음 레퍼토리 곡으로 넘어갑니다. 30분마다 휴식 알림, 끝나면 통증·난이도 자가 평가
- **루틴 편집**(홈 → 루틴 편집): 항목 빼기·더하기·순서·블록 시간을 바꿔 그 단계 템플릿으로 저장하면 다음 세션부터 그 구성으로 짭니다(쌍·코드·템포는 앱이 그날 맞게 채움). "기본으로 되돌리기"로 지웁니다. 설정의 세션 길이는 기본이 "단계 기본값"이고, 분을 직접 고치면 그 길이로 맞춥니다.
- **추천 카드**: 2주째 제자리인 항목의 처방(1분 체인지 → 앵커·공중 드릴, 한 줄씩 확인, 일주일 −10 BPM), 세 손가락 G로 바꾸기 제안, 조건부 진급
- **연습**: K1 자가 체크 카드(자세·피크·박 세기·발 박자), E16 프렛 위치 비교, 단음 시퀀스 연습 — E9 크로매틱, E10 스케일 사다리(1–5단계, 4사이클 연속 무실수로 단계 졸업, 틀린 음은 위치와 반음 차이로 표시, 반주 선택), E11 해머온(하루 상한), E12 새끼손가락, E17 단음 리프(TAB) — 은 마이크가 사이클마다 판정하고 마이크가 없으면 자가 보고, E3 정밀 빠른 체인지(1분 체인지 정체 처방), Q3 6·5번 줄 음이름(이름 → 튕기기), Q4 인터벌·진행 귀 훈련, Q5 TAB 읽기 퀴즈, S 연주 단계 반주(play-along: 이어폰이면 그대로 판정, 스피커면 반주 소리를 가려 박 1을 판정하고 코드 확인은 "참고"로만 보여 줌), 그리고 v1의 E0 튜닝, E1 코드 정밀 체크(한 줄씩 판정·스트럼 베타·수동·귀 먼저), E2 1분 코드 체인지(첫 스트럼으로 자동 시작, 자동/탭/직접 카운트), E4 앵커·공중 체인지, E5 스트러밍 패턴 사다리, E6 박 1 체인지, E7 손가락 스트레칭, E8 한 줄 교대 피킹, Q1 다이어그램 퀴즈, Q2 코드 기억 퀴즈, Q3 개방현 음이름, Q4 메이저/마이너 귀 훈련, S 연습곡(학습/연주 모드)
- **커리큘럼** Stage 0–11, 데이터로 정의된 진급 기준과 진행 상황, **초급 1 졸업 시험**(항목별 통과 기록, 통과하면 Stage 8로), Stage 11 기준을 채우면 **초급 2 수료**(날짜 기록, 이후 레퍼토리·복습·약점 위주 루틴). 단계 페이지의 **이 단계 연습하기**에서 아무 단계의 연습이든 골라 **바로 하거나**, 여러 개를 골라 순서대로 **나만의 세션**으로 할 수 있습니다(템포·쌍·코드는 오늘 루틴처럼 기록에서 채움, 기록은 평소처럼 남음. 지금 단계가 아닌 단계의 세션은 지금 단계의 최소 세션 수에 들어가지 않음)
- **진도**: 주간 연습 시간, 쌍별 1분 체인지 추이, 코드×줄 깨끗 비율, 패턴별 최고 BPM, 타이밍 평균·흔들림, 세션 기록, 간격 반복 복습 큐
- **도구**: 튜너(줄 모드·크로매틱), 메트로놈(탭 템포, 박자·세분, 카운트인, 음소거 마디, 시각 전용, 템포 사다리), 코드 라이브러리(다이어그램·기대 음·들어 보기)
- **연주 중 바로 보기**: 마이크로 하는 E6 박 1 체인지·E5 스트러밍·E8 교대 피킹은 마디가 끝나고 1초 안에 그 마디 결과가 마디 칸에 뜹니다(✓ 제때, ± 조금 어긋남, ✗ 많이 놓침, ■ 멈춤 — E6은 박 1이 몇 ms 늦거나 빨랐는지와 바뀐 코드가 맞았는지, E5는 패턴 칸마다 맞음·놓침·더 친 것). 기록은 끝난 뒤 다시 계산한 값입니다.
- **하는 법**: 모든 연습은 시작 버튼 위에 **하는 법**을 펼쳐 보여 줍니다 — 왼손·오른손이 할 일, 메트로놈 클릭 하나에 몇 번 치는지, 어떻게 판정하고 무엇을 하면 다음 템포로 올라가는지(앱의 실제 기준값), 그리고 줄 번호·손가락 번호(1 검지 … 4 새끼)·TAB·코드 다이어그램·뮤트 스트럼 같은 처음 보는 말. 연습 중에는 접혀 있고 눌러서 다시 볼 수 있습니다.
- **단음 리프·스케일·크로매틱 TAB**: 줄 번호(1–6)가 선 옆에, 누를 손가락 번호가 TAB 아래 "손" 줄에 나옵니다(TAB 숨김이면 같이 숨음). 리프는 마디선과 **말로 읽은 리프**("1마디: 6번 줄 개방 ×2 → 6번 줄 3프렛(3번 손가락) ×2"), 시작 전 **들어 보기(M)**로 합성음을 먼저 들을 수 있습니다(시작하면 바로 멈춰 마이크가 듣지 않음).
- **홈의 오늘 한 연습**: 오늘 연습을 마치면 홈에 **오늘 한 연습** 목록(실제로 한 순서, 반복은 ×2)이 먼저 나오고, 그 아래 "한 번 더 하면" 할 다음 세션 목록이 나옵니다. 리듬·기술 칸은 세션마다 돌아가며 바뀌어서 두 목록이 다를 수 있습니다.
- **코드 정밀 체크(한 줄씩)**: 기타 몸통을 친 소리처럼 줄 소리가 아닌 건 판정하지 않고 "그 줄을 한 번 더" 쳐 달라고 하며, 앞에서 친 줄이 계속 울려도 다음 줄을 가려 듣습니다. 다음 줄을 판정이 뜨기 전에 빨리 쳐도 받습니다. **설정 → 판정 감도**(둔감·보통·민감)로 작은 소리를 얼마나 판정할지 고릅니다.
- **마이크가 없거나 거부돼도** 모든 연습을 수동·자가 판정으로 진행할 수 있습니다. 마이크 판정은 보조 수단이고, 내 귀가 먼저예요.

## 요구 사항

- 사용: 최신 Chrome / Safari(iPad·iPhone은 Safari), **HTTPS 또는 localhost**(마이크·화면 꺼짐 방지·오프라인에 필요)
- 개발: Node.js ≥ 22.12(확인: 24.3), npm 11. E2E는 `npx playwright install chromium webkit`
- 실녹음 벤치마크(`bench:guitarset`)는 처음 실행 때 GuitarSet(Zenodo, 약 700 MB 내려받기, 풀면 약 2 GB)을 `data/`로 내려받습니다.

## iPad에서 쓰는 법

1. Safari로 배포 주소(또는 `npm run dev:https`의 Network 주소)를 엽니다.
2. 공유 → **홈 화면에 추가**. 홈 화면의 "기타" 앱으로 열면 전체 화면이고, 한 번 연 뒤에는 오프라인에서도 열립니다.
3. 처음 설정에서 마이크를 허용하고, 기기를 기타에서 30–60 cm 떨어진 곳에 둡니다(블루투스 이어폰 마이크 대신 내장 마이크).
4. 손이 기타 위에 있을 때는 키보드나 블루투스 페이지 터너 페달로 조작합니다: Space·PageDown(→) 시작, 끝나면 Space 다시 하기(블록 시간이 남은 마디·문항 연습은 "이어서 한 번 더", 사다리 다음 템포)·PageDown(→)·Enter 다음 항목, PageUp(←) 이전 항목, ↑↓ 보정, 1/2/3 수동 판정, Esc 중단(한 번 더 눌러 확인). 연습 옵션 키: E1 M 모드 바꾸기·E 귀 먼저, E5 V 시각 큐 숨기기, 연습곡 ↑↓ 템포·L 구간 반복·H 악보 숨김·B 반주 켜기(연주 단계)·E 이어폰/스피커, 단음 연습(스케일·크로매틱·해머온·리프 등) H TAB 숨김. 페달 버튼은 설정 > 키·페달에서 원하는 동작에 연결할 수 있습니다(그 키가 원래 다른 동작의 기본 키였으면 화면이 알려 주고, 배운 동작이 먼저입니다).

자세한 배포·설치 절차: [`docs/DEPLOY.md`](docs/DEPLOY.md). 실기기 검증 순서: [`docs/MANUAL_VALIDATION.md`](docs/MANUAL_VALIDATION.md).

## 데이터와 백업

- 모든 기록은 브라우저 IndexedDB(연습 기록·설정·캘리브레이션)와 OPFS(녹음 키트 오디오)에 저장되고, 서버로 보내지 않습니다.
- 시작할 때 브라우저에 저장소 보호(`storage.persist`)를 요청합니다. 그래도 Safari는 데이터를 지울 수 있으니 **설정 → 백업 → 내보내기**(JSON 파일)를 가끔 하세요. 마지막 백업 후 7일이 지나면 홈에 알림이 뜹니다.
- 가져오기는 미리보기(테이블별 건수) 후 **합치기**(같은 기록은 건너뜀) 또는 **바꾸기**(2단계 확인)입니다. 연습 기록(Attempt)은 추가만 되고 수정·삭제되지 않으며, 지표·스킬·복습 큐는 기록에서 언제든 다시 계산됩니다.

## 아키텍처 요약

```
UI(React) ─ 연습 플러그인 러너·세션 러너·진급 ─ AudioEngine ─┬─ AudioWorklet(캡처·onset)
                                                            └─ DSP Worker(판정) ─ src/dsp(순수)
데이터: Dexie(IndexedDB) · 콘텐츠·규칙: src/content(시드+zod) · 음악 이론·규칙: src/domain(순수)
```

- 판정기(Mode A 한 줄씩, Mode B 스트럼 베타, Mode C 코드 분류, Mode D 타이밍, 단음 시퀀스 검증, 반주 누출 마스킹, 튜너, RTT)는 의존성 없는 TypeScript 순수 함수이고, 합성 벤치마크(dev/test split)와 공개 실녹음 데이터셋(GuitarSet)으로 임계값을 검증합니다. 버징·스트럼 방향·해머온·팜뮤트·셈여림은 정답 데이터가 없어 "참고(베타)"로만 재고 보고합니다.
- 연습 종류는 플러그인(params/result 스키마 + 러너 + 화면)이라 코어 수정 없이 추가할 수 있습니다.
