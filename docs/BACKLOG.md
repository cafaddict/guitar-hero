- Stage 8–11 실제 진행(콘텐츠 데이터는 v1에 있고 잠금 상태)
- 실제 곡(저작권 곡) 콘텐츠, 백킹 트랙 오디오

## 판정(DSP)
- 버징·스트럼 방향 판정을 하드 판정으로(v1.1은 베타·보고 전용), 같은 음이 겹치는 줄 식별
- 캘리브레이션 템플릿 기반 NNLS 분해로 스트럼(Mode B)의 "확인 불가" 줄 줄이기
- basic-pitch(ONNX) second opinion
- 실기기 녹음 키트 fixture가 쌓이면 Mode B 임계값·Mode A 뮤트 기준 재조정(`bench:real` 결과 기준)
- WASM DSP 커널은 프로파일상 필요가 증명될 때만(현재 판정 지연 수 ms)

## 판정(DSP) — v1.1 베타에서 이어지는 과제
- 스트럼 방향(베타, dev 0.54): 줄별 고유 partial 시각 대신 줄별 전사(예: Murgul et al.)로 줄 onset을 직접 추정 — 옥타브 관계가 많은 코드에서 이웃 줄 누설을 피한다(DSP.md 17절)
- 버징(베타, dev 검출 0.62): 감쇠 초반 진폭 변조·spectral flatness 특징 추가, 실녹음 버징 데이터로 템플릿 보정
- 스피커 반주 아래 Mode C(베타, dev 0.76): 반주 템플릿을 스펙트럼 차감에 써서 분류 전 반주 성분 제거
